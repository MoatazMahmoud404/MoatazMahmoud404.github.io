## Setting Up the Chirpy Theme

Chirpy makes it easy to get started with a professional-looking Jekyll site. Here's how you can set it up:

### 1. Prerequisites
> Ensure you have Ruby, Bundler, and Jekyll installed on your system.
{: .prompt-tip }

- [Install Ruby](https://www.ruby-lang.org/en/documentation/installation/)
- [Install Jekyll and Bundler](https://jekyllrb.com/docs/installation/)

### 2. Installing Chirpy
You can add Chirpy to your site in two main ways:

**A. Fork the Chirpy Starter Repo**
1. Go to the [Chirpy Starter Repo](https://github.com/cotes2020/chirpy-starter) and click "Use this template" to create your own repository.
2. Clone your new repository to your local machine.

**B. Add Chirpy to an Existing Jekyll Site**
1. Add Chirpy as a remote theme in your `_config.yml`:
   ```yaml
   remote_theme: cotes2020/chirpy
   ```
2. Run `bundle install` to update dependencies.

### 3. Basic Configuration
Edit your `_config.yml` to personalize your site:
- Set your site title, description, and author.
- Configure navigation, social links, and theme color.

> Tip: Chirpy's documentation provides detailed explanations for each configuration option.
{: .prompt-info }

Now your site is ready to use Chirpy! Next, let's explore how to write beautiful content with Markdown.
